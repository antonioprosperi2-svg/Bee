BeeTouchControls

Disegna cinque pulsanti rotondi e, quando un tocco ci finisce sopra, chiama input.setKey con ArrowLeft, ArrowRight, ArrowUp, ArrowDown o il carattere spazio.

Costruttore

new BeeTouchControls(canvas, input)

Parametri

ParametroPredefinitoDescrizione
canvas—Elemento su cui registra touchstart, touchmove e touchend, e da cui draw legge width e height.
input—Oggetto con setKey. btnSize parte da 60 e margin da 20.

Metodi pubblici

MetodoParametriDescrizione
getButtonAt(x, y)x, yRestituisce il nome del pulsante se la distanza dal centro è minore di btnSize / 2 + 15, altrimenti null.
getCanvasCoords(touch)touchConverte clientX/clientY del tocco nelle coordinate del canvas.
handleTouch(e)epreventDefault, rilegge i tocchi attivi e chiama input.setKey true sui pulsanti toccati e false su quelli rilasciati.
handleTouchEnd(e)eCome handleTouch, sugli identificatori che non sono più in e.touches mette la chiave a false.
draw(ctx)ctxPosiziona i cinque centri e disegna un cerchio per pulsante, bianco se attivo, con il simbolo corrispondente.

Esempio

import { BeeInput } from './BeeInput.js';
import { BeeTouchControls } from './BeeTouchControls.js';

const input = new BeeInput(canvas);
const touch = new BeeTouchControls(canvas, input);
const nome = touch.getButtonAt(40, canvas.height - 40);
touch.draw(ctx);
input.endFrame();
