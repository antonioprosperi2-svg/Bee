BeeEntity

Nodo dello scene graph: coordinate locali e mondo, velocità, gerarchia di figli e aggancio di un collider rettangolare. Il moto e le collisioni AABB passano da BeePhysics, il disegno dei figli da BeeEntityRenderer.

Costruttore

new BeeEntity(x = 0, y = 0, width, height)
new BeeEntity({ x, y, width, height, ... })

Se il primo argomento è un oggetto, i campi sotto sono letti da lì. Altrimenti x, y, width e height sono posizionali. width e height omessi usano BeeEntity.defaults (32 e 32).

Export dello stesso file

Nello stesso modulo ci sono anche questi oggetti. Non sono metodi di BeeEntity.

MetodoParametriDescrizione
BeePhysics.integrate(entity, dt)entity, dtAggiorna vy con gravità e maxFallSpeed, frena vx con friction o airFriction, poi translate. Azzera isGrounded.
BeePhysics.overlaps(a, b)a, btrue se i due AABB mondo si intersecano. false se manca un oggetto o se a e b sono lo stesso.
BeePhysics.resolveSolid(entity, solid)entity, solidSpinge l'entità fuori dal solido sull'asse di penetrazione minore. true solo in caso di atterraggio.
BeeEntityRenderer.renderChildren(entity, ctx, engine)entity, ctx, engineDisegna i figli visibili. Usa engine.drawEntity se esiste, altrimenti child.draw.

Esempio

import { BeeEntity } from './BeeEntity.js';

BeeEntity.configure({ gravity: 900 });

const blocco = new BeeEntity(100, 50, 40, 40);
const figlio = new BeeEntity({ x: 8, y: 0, width: 16, height: 16, name: 'ala' });
blocco.addChild(figlio);
blocco.addRectCollider();
blocco.translate(2, 0);

const altro = new BeeEntity(120, 50, 40, 40);
if (blocco.collidesWith(altro)) {
  blocco.resolvePlatformCollision(altro);
}

blocco.update(0.016, null, null);
blocco.destroy();
